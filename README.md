# Catpaw Mobile Demo

参考提供的三张手机截图制作的移动端设计原型，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 预览

直接打开 `index.html`，或在项目目录启动静态服务：

```sh
python3 -m http.server 5173
```

打开 http://localhost:5173 。手机端铺满屏幕，桌面端显示居中的 390 × 844 手机预览，窗口空间不足时整体等比缩放；真实手机按可用视口自适应。

桌面预览包含模拟 iOS 状态栏；窄屏网页隐藏模拟栏，并使用 `safe-area-inset-top` 适配真机顶部安全区域。

## 交互

- 点击左上角图标展开侧栏，主页面向右移动；点击右侧页面或 Escape 收起。
- 侧栏包含新任务、专家、技能、资料库、项目及对话历史；点击内置的 `New Chat` 可直接查看长回复排版示例。
- 对话使用 Figma 参考的紧凑单行输入区；文字换行后自动展开为多行，上限 7 行，支持全屏编辑。点击输入区直接聚焦真实文本框，手机端使用系统键盘。Enter 换行，Ctrl/Cmd + Enter 发送。回复包含标题、列表、重点、参考链接、复制、赞踩、时间和模拟停止回复。对话历史保存在当前页面内存，刷新后重置。
- 点击输入区「＋」打开附件面板，点击「技能」进入「我的技能」。
- 选择技能后，输入区展示技能标签，可移除。
- 支持本地附件选择、快捷提示、项目切换、模式选择、对话列表与新建对话。
- 支持发送消息并显示明确标注的演示回复，尚未连接真实 AI 或上传服务。
- 支持 Escape、点击遮罩或顶部手柄关闭面板；尊重系统减少动画设置。
- 语音转写使用浏览器提供的语音识别能力，需浏览器支持及麦克风权限。

Git 远端：`git@github.com:tianyiliu1905/catpaw-mobile.git`

## 设计系统

与 `catpaw-desktop-ui` 统一语义色、圆角、间距、字体家族、线性图标与品牌素材，字号使用手机端尺寸。共享变量见 `design-tokens.css`，来源与适配说明见 `DESIGN_SYSTEM.md`。

## 桌面演示键盘

桌面浏览器点击输入区会显示 iPhone 风格的静态键盘，并将输入区推到键盘上方。支持点击下箭头、页面空白或 Escape 收起；多行和全屏编辑状态也可使用。实际文字仍通过电脑键盘输入。iPhone、iPad、Android 保留系统输入键盘，不重复展示演示键盘。

键盘素材来自 MIT 开源的 [kitlangton/ios-kit](https://github.com/kitlangton/ios-kit)，原始 440 × 344 画布在 390px 宽预览中等比显示为约 305px 高。许可证及适配说明保存在 `vendor/ios-kit/`。

## 知识库选择

点击加号面板中的「知识库」，在底部面板中开启企业知识并多选；首次开启默认全选，关闭仅暂停使用并保留勾选，再开启恢复原选择，开关和勾选立即生效，返回或关闭面板都会保留当前选择，无需点击完成。启用后，输入框展开时会显示绿色知识库按钮。发送后清除本轮选择，并将引用名称保留在消息中。当前使用本地演示数据。

## 手机扫码预览（推荐）

依赖已配置在 `package.json`。首次在新电脑上使用时运行 `npm install`，之后：

```sh
npm run preview
```

也可以在 Mac 上双击 `手机预览.command`。

- 打开终端打印的扫码面板：`http://127.0.0.1:5174/__preview/`。
- 手机和电脑连接同一 Wi-Fi，用相机扫码，在 Safari / Chrome 中打开。
- 保存 HTML、CSS、JS 或图片后，手机自动更新。点击和表单输入不会跨设备同步。
- 支持从面板切换 HTML 页面；有多个网络接口时可选择手机所在的网络。
- 文件保存在电脑上，电脑和预览服务需保持运行。终端按 Ctrl+C 停止。
- 原有 `5173` 预览服务不受影响；扫码预览默认使用 `5174`。

预览其他文件夹或修改端口：

```sh
npm run preview -- "/完整路径/HTML文件夹" --entry index.html --port 5175
```

如果手机连不上，先核对两台设备是否在同一个 Wi-Fi，再检查电脑的防火墙是否允许 Node.js 接入局域网。访客网络可能不允许设备互相访问。手机需使用二维码里的局域网地址，不能使用 `localhost` 或 `127.0.0.1`。

如果同一 Wi-Fi 仍无法访问，可打开手机个人热点，让电脑连接该热点，再刷新扫码面板；面板会自动重新读取电脑的网络地址并生成新二维码，无需重启服务。

## 交互 / 设计稿切换

页面顶部可以切换「交互演示」与「设计稿」。设计稿模式直接展示已生成的本地 PNG，双击 HTML 也能查看和放大；图片位于 `assets/design-review/`。HTTP 预览下点击「重新生成」可在独立 Demo 实例中更新「添加知识库」的 9 个步骤图片：默认首页、展开输入、添加面板、选择知识库、开启企业知识、按需调整、已添加知识库、收起输入、专家与知识库并排。不会修改主 Demo 中的草稿或知识库选择。

每张图以 390 × 844 的手机画面生成 2 倍 PNG，支持放大查看和单张下载；样式更新后可以重新生成。请通过 HTTP 预览服务打开，直接双击 HTML 文件时浏览器可能限制截图功能。

直接进入设计稿：`http://127.0.0.1:5173/?view=design`。

页面截图依赖 MIT 开源的 html-to-image 1.11.13，本地运行文件和许可证位于 `vendor/html-to-image/`。

### 知识库交互对比

在页面空白处，各方案说明旁的「切换」按钮可切换方案一、方案二、方案三；当前方案显示「当前」。方案一先开启企业知识再调整列表；关闭开关暂停使用并保留选项，再次开启恢复。方案二提供「全选」复选框，也可直接独立添加或移除任一知识库；全部选中时显示勾选，取消任一单项后全选恢复未勾选的描边状态；取消全选可清空。所有更改即时生效。方案二地址参数为 `?knowledge-mode=independent`，设计稿会展示对应版本的 9 步图片。

知识库和专家标签位于输入框内部、正文上方，可以并排显示。点击标签重新选择；专家通过叉号移除，知识库在选择面板中调整或清空；空输入点击外部仍会收起文字区，已选标签保留。

「方案三」通过 `?knowledge-mode=icons` 打开：开关关闭隐藏列表；开启默认使用全部并展开列表，面板不收起。首次点击单项“指定”按钮进入逐项添加，选择一项并返回首页；继续添加其他项会累计，同一项不重复计数。列表始终显示“指定”，不显示选中状态；输入框只选一篇时显示知识文档名称，多篇时显示「知识＋数量」。设计稿资源位于 `assets/design-review-icons/`。
